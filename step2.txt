How to get logs of a specific time interval?
steps:
log --help ; nothing useful
man log ; log show  [--last num[s|m|h|d] | boot] [--last24] [--today] [--yesterday]
log show --last 1h ; still very much
log show --last 1s ; 👍

to store it in a file ?
log show --last 50s > log_history.txt

to check file size:
